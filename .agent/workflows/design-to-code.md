# DESIGN TO CODE WORKFLOW

## PHASE 1 — DISCOVER

Read all project instructions.

Read:

- .agent/AGENTS.md
- .agent/rules/*
- relevant workflow files

Understand the project before changing anything.

---

# PHASE 2 — INSPECT FIGMA

Use the available Figma MCP.

Find:

- target file
- target frame
- target page

Inspect:

- hierarchy
- dimensions
- typography
- spacing
- colors
- effects
- assets
- components
- interactions

---

# PHASE 3 — BUILD DESIGN MAP

Create an internal representation:

Page
├── Header
├── Hero
├── About
├── Skills
├── Projects
├── Experience
├── Contact
└── Footer

For each section record:

layout
dimensions
spacing
typography
assets
animation
responsive behavior

---

# PHASE 4 — IMPLEMENT

Implement the structure first.

Do not begin with animation.

First achieve static visual accuracy.

---

# PHASE 5 — TYPOGRAPHY

Load fonts.

Match:

- family
- weight
- size
- line height
- letter spacing
- wrapping

---

# PHASE 6 — VISUAL STYLING

Implement:

- colors
- gradients
- borders
- shadows
- radius
- backgrounds
- images

---

# PHASE 7 — ANIMATION

Implement animation according to the animation specification.

Do not add unrelated animations.

---

# PHASE 8 — RESPONSIVE

Implement responsive behavior.

Test:

desktop
tablet
mobile

---

# PHASE 9 — VISUAL QA

Render.

Compare against reference.

Create a mismatch list.

Fix mismatches.

Render again.

Repeat.

---

# PHASE 10 — FINALIZATION

Confirm:

- visual accuracy
- responsiveness
- animations
- code quality
- accessibility
- performance

Then report completion.
