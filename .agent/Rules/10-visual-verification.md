# DIFFERENCE CLASSIFICATION

Classify each mismatch as:

CRITICAL
MAJOR
MINOR

Critical:
- wrong layout
- wrong section size
- wrong typography
- missing element

Major:
- wrong spacing
- wrong image size
- wrong alignment
- wrong animation

Minor:
- small radius difference
- subtle shadow difference
- tiny spacing difference

Fix critical issues first.

---

# ITERATION

After every major fix:

Render again.

Never assume the fix worked without verification.

---

# FINAL COMPARISON

The final implementation must be compared against:

- reference screenshot
- Figma frame
- specified animation behavior
- responsive requirements

Only then consider the task complete.
