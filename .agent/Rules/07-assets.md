# ASSET MANAGEMENT

Use the original design assets whenever possible.

## PRIORITY

1. Figma exported asset
2. Project asset
3. User-provided asset
4. CSS recreation
5. Placeholder only when absolutely necessary

---

# IMAGES

Preserve:

- aspect ratio
- crop
- object position
- border radius
- size
- quality

Do not unnecessarily compress images.

---

# ICONS

If an icon exists in the design:

Use the actual icon or appropriate vector asset.

Do not substitute a random icon with different proportions.

---

# FONTS

Use the exact font when available.

If the font is unavailable:

Choose the closest practical fallback.

Document the substitution.

---

# LOGOS

Never redesign a provided logo.

Preserve its proportions and visual appearance.
