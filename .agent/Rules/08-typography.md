# TYPOGRAPHY RULES

Typography is a major part of pixel-perfect implementation.

Inspect:

- font family
- font weight
- font size
- line height
- letter spacing
- text transform
- width
- alignment

---

# HEADING

Large headings often control the entire layout.

Verify:

- exact font
- exact weight
- exact line break
- max-width
- letter spacing
- line height

Do not allow automatic wrapping to create a different composition.

---

# TEXT WRAPPING

If the reference contains a specific line break:

Preserve it when necessary.

Use controlled max-width or responsive line breaks rather than relying entirely on browser wrapping.

---

# FONT LOADING

Ensure fonts load before visual verification.

Do not compare layout before the intended fonts are available.
