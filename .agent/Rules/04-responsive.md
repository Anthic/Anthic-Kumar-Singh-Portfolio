# RESPONSIVE DESIGN RULES

The reference design may represent only one viewport.

Build a responsive system around it.

## DESKTOP

Preserve:

- composition
- typography
- spacing
- visual hierarchy

---

## TABLET

Adapt:

- columns
- spacing
- typography
- navigation
- card layout

---

## MOBILE

Prioritize:

- readability
- hierarchy
- usability
- touch targets
- visual consistency

Do not simply scale desktop down.

---

# BREAKPOINTS

Use project-standard breakpoints when available.

If none exist, choose reasonable responsive breakpoints based on content requirements.

Do not create many unnecessary breakpoints.

---

# DECORATIVE ELEMENTS

Large decorative objects may need:

- repositioning
- scaling
- hiding
- simplified animation

on smaller screens.

Do not allow decorative elements to break usability.
